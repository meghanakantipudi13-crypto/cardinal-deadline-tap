# Cardinal Deadline Tracker — Hermes skill tap

A small original, credential-free skill for synthetic or non-sensitive assignment deadlines. It creates and updates tasks, tracks completion, lists upcoming work and returns due-soon reminders. Explicit timezone offsets avoid ambiguous deadlines.

Install this repository as a Hermes GitHub skill tap: `hermes skills tap add meghanakantipudi13-crypto/cardinal-deadline-tap`, then `hermes skills install meghanakantipudi13-crypto/cardinal-deadline-tap/skills/cardinal-deadline-tracker`. Keep Hermes's normal installation security scan enabled. Repository: https://github.com/meghanakantipudi13-crypto/cardinal-deadline-tap .

The skill includes a Python standard-library helper. Data uses a local SQLite database under `CARDINAL_STATE_DIR`, or the user's standard application state directory. The helper does not send messages, email, or make network requests. Reminders are returned on `due-soon`; an operator must configure their preferred scheduler/delivery separately. Never claim automatic notifications until that schedule and delivery are verified.
